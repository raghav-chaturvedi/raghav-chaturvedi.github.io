The GitHub repo for this project is located here. In this project, I use the DPO algorithm to optimize a 2-link swimming robot using the OpenAI Gymnasium Swimmer-v5 simulator. The swimmer has two joints, which are controlled by a policy with a continuous action space $\mathbb{A} = [−1, 1]^{2}$. At each timestep, the policy outputs a torque vector applied to the joints. The goal is to maximize the swimmer's velocity. 

[Direct Preference Optimization (DPO)](https://arxiv.org/pdf/2305.18290) was developed in the context of finetuning Large Language Models (LLMs). The common practice in LLM finetuning is the following:

- Generate multiple responses from the LLM using a prompt
- Get a human to rank the responses according to their preferences
- Train a reward model that maps a point in (output, prompt) space to a reward score
- Use PPO to align the LLM to achieve high reward from the reward model.

This process is called Reinforcement Learning through Human Feedback (RLHF). However, the DPO paper showed that it's possible to perform finetuning on an LLM without using a reward model, but through optimizing the LLM directly.

The objective function in RLHF

\begin{equation}
R = \max_{\pi_\theta} 
\mathbb{E}_{x \sim \mathcal{D},\, y \sim \pi_\theta(y \mid x)}
\left( r_\phi(x, y) \right) 
- \beta \, D_{\mathrm{KL}}\left( \pi_\theta(y \mid x) \,\|\, \pi_{\mathrm{ref}}(y \mid x) \right)
\end{equation}

is essentially just maximising the total reward collected with some KL constraints that restrict the model from changing too much (avoid reward hacking). To obtain the DPO formulation, it's easy to show that this objective function can be maximised analytically and has the following solution,

\begin{equation}
\pi_r(y \mid x)=\frac{1}{Z(x)} \pi_{\mathrm{ref}}(y \mid x) \exp \left(\frac{1}{\beta} r(x, y)\right)
\end{equation}

, where $Z(x)=\sum_y \pi_{\mathrm{ref}}(y \mid x) \exp \left(\frac{1}{\beta} r(x, y)\right)$ is a partition function borrowing the terminology from thermodynamics. This equation can now be used to model the reward difference and be plugged into the Bradley-Terry model (or any other preference model) to give the DPO loss,

\begin{equation}
\mathcal{L}_{\mathrm{DPO}}\left(\pi_\theta ; \pi_{\mathrm{ref}}\right)=-\mathbb{E}_{\left(x, y_w, y_l\right) \sim \mathcal{D}}\left(\log \sigma\left(\beta \log \frac{\pi_\theta\left(y_w \mid x\right)}{\pi_{\mathrm{ref}}\left(y_w \mid x\right)}-\beta \log \frac{\pi_\theta\left(y_l \mid x\right)}{\pi_{\mathrm{ref}}\left(y_l \mid x\right)}\right)\right)
\end{equation}

which can now be minimized using your favourite optimizer. The pipeline in this project is as follows:

- Initialize a continuous Gaussian policy
- Collect trajectories and rewards at each timestep using this policy
- Pair up the trajectories and label their preferences using the Bradley-Terry model
- Run DPO on this collected dataset to find optimized policy
