The GitHub repo for this project is located here. In this project, I use the DPO algorithm to optimize a 2-link swimming robot using the OpenAI Gymnasium Swimmer-v5 simulator. The swimmer has two joints which are controlled by a policy with a continuous action space A = [−1, 1]2. At each timestep, the policy outputs a torque vector applied to the joints. The goal is to maximize the swimmer's velocity. 

[Direct Preference Optimization (DPO)](https://arxiv.org/pdf/2305.18290) is an RL technique that avoids doing RL. Instead of using reward models trained on human-labeled preferences, DPO aims to directly optimize the policy (LLM) while using the same objective function as existing RLHF algorithms. 

For  preference sampling using a model (policy) pi, two generated trajectories (yw, yl) are ranked by a human labeler. It's assumed that there exists an underlying reward distribution that models the preferences generated by the labeler. A popular choice for this distribution p* is the Bradley-Terry (BT) model,

$\begin{equation}
p^*\left(y_w \succ y_l \mid x\right)=\frac{\exp \left(r^*\left(x, y_w\right)\right)}{\exp \left(r^*\left(x, y_w\right)\right)+\exp \left(r^*\left(x, y_l\right)\right)} = \sigma(r^*(x,y_w)-r^*(x,y_l))
\end{equation}$

, where $\sigma$ is the sigmoid function. Under the BT model, we can parametrize a reward model and estimate it's parameters by minimzing the following log-likelihood loss,

\begin{equation}
\mathcal{L}_R\left(r_\phi, \mathcal{D}\right)=-\mathbb{E}_{\left(x, y_w, y_l\right) \sim \mathcal{D}}\left[\log \sigma\left(r_\phi\left(x, y_w\right)-r_\phi\left(x, y_l\right)\right)\right].
\end{equation}

In conventional LLM fine-tuning using RLHF, we use this reward model to provide feedback to the actual LLM by maximizing the earned reward within some KL-divergence constraints. Essentially maximizing,

\begin{equation}
R = \max _{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta(y \mid x)}\left[r_\phi(x, y)\right]-\beta \mathbb{D}_{\mathrm{KL}}\left[\pi_\theta(y \mid x) \| \pi_{\mathrm{ref}}(y \mid x)\right].
\end{equation}

To obtain the DPO formulation, it's easy to show that the constraint optimization problem for R can be solved analytically and has the following solution,

\begin{equation}
\pi_r(y \mid x)=\frac{1}{Z(x)} \pi_{\mathrm{ref}}(y \mid x) \exp \left(\frac{1}{\beta} r(x, y)\right)
\end{equation}

, where $Z(x)=\sum_y \pi_{\mathrm{ref}}(y \mid x) \exp \left(\frac{1}{\beta} r(x, y)\right)$ is a partition function borrowing the terminology from thermodynamics.
